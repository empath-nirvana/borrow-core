# EffModelRel

Phase B of #235: a binary logical relation, and a unary resource-safety relation, for the
calculus of `experiments/EffModel` (adjoint modes, effects as models, capabilities as comodels,
running as their tensor, instances generated by `ν`). The calculus is re-stated here intrinsically
typed, with a denotational semantics into finite trees, so the laws are theorems about
contextual equivalence rather than `#guard`s. Standalone: no Mathlib, imported by nothing.

    lake build EffModelRel

The design, the theorem table and the open items are in `docs/effect-model.md` §8 (phase B,
#247) and §9 (the narrow run, #249: the TR's rule fixes, rows on types, effect safety, the
ownership fragment, and a cell holding a continuation).
