# Experiments

Probes. Nothing in `Paper/`, `Support/`, `Examples/` or `Core/` imports anything here: an
experiment that works becomes an entry in `SPEC.md`, and the entry is then implemented in the
library. None of these libraries is a default target.

Each experiment builds against this repository's `Paper`/`Support` (and `Examples`, for
`CBPVWorld`; `Core`, for `Optics`; `Records`, for `Places`; `Places`, for `LeafPlaces`; `CBPVWorld`, for `Recursion`; `LeafPlaces`' `Steps.lean`, for `CBPVMu`'s `DelayNaive.lean`; `Core` and `Optics`, for
`FrameTheorems`). Module names are unique across the libraries: the
`Experiments` library's modules are `CBPVSplit.Split`, `ModesLabels.Modes`, `Shifts.Shifts`,
`BorrowedClosures.Reborrow` and `BorrowedClosures.EnvCheck`.

These experiments were developed in `~/repos/borrow_lang/Experiments/`; the last `borrow_lang`
commit containing them is `a31b498`. An archived experiment's README names the commits that hold
its code.

**Building the experiments.** The library's machine gained a host parameter (SPEC §8, commit
`e4f41e0`), and the experiments were not updated. Check out `c8694fa` or earlier to build them.
`Optics` and `FrameTheorems` are the exceptions: they are written against the current `Core`
and build at `main`.
