# EffModel

An executable model of the effects design of #235 (phase A): adjoint modes, effects as models
(handlers into any computation type), capabilities as comodels (runners), running as their
tensor, and instances generated by `ν`. Standalone: no Mathlib, imported by nothing.

    lake build EffModel

builds it and checks every acceptance test (`#guard`s in `EffModel/Tests.lean`), printing the
matrix. The design, the mapping to the papers and the results are in `docs/effect-model.md`.

| file | contents |
|---|---|
| `Syntax.lean` | modes, bounds, rows, types, terms |
| `Typing.lean` | the judgement: grades, independence, scope, T1 |
| `Eval.lean` | the CK machine and its observable |
| `Prelude.lean` | effects, handlers, comodels, implementations of an instance |
| `Laws.lean` | the context suite and the laws |
| `Programs.lean` | the programs that broke us |
| `Refusals.lean` | what linearity must refuse, each with an accepted control |
| `Tests.lean` | the `#guard`s and the matrix |
