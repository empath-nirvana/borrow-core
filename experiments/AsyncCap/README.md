# AsyncCap: borrows held across a suspension, under one named hypothesis

The Lean half of `docs/async-capabilities.md` (#52). It states the relaxed rules and `PinLaw`
against Core's definitions, and proves the Fundamental Property and adequacy of the extended
judgment from `PinLaw`.

Build with `lake build AsyncCap`. It imports `Core`, `GhostEnd.Drop` and (for `LoopTerm.lean`)
`Frontend.Check.CrossCheck`. The library does not import it, and `Core` is unchanged.

**Hygiene.** No `sorry`, `axiom`, `native_decide`, `opaque`, `partial`, `unsafe` or
`implemented_by`. Every result's axioms are within `[propext, Classical.choice, Quot.sound]`
(`lake env lean experiments/AsyncCap/scripts/Axioms.lean`).

**Sorries: none.** `PinLaw` is not a `sorry` and not an axiom: it is a `structure … : Prop`, and
each theorem that uses it takes it as a hypothesis `(hPin : PinLaw)`.

## `PinLaw`

`PinStop`: R1's compatibility lemma as a `Prop`, at the rule's premises.

`PinLoop`: R2's compatibility lemma as a `Prop`.

Both quantify over code only through `PDerives` derivations. Neither is pointwise over
configurations. `docs/async-capabilities.md` §4 gives the evidence, the remainder, and what would
falsify each.

## How the files are made

`Derives.lean` and `Fundamental.lean` are generated by `scripts/gen.py` from
`Core/Fundamental.lean` (`CDerives` and `fundamentalC`) and the templates
`scripts/Derives.tmpl.lean`, `scripts/Fundamental.tmpl.lean`. Edit a template and rerun
`python3 experiments/AsyncCap/scripts/gen.py` from the repository root. A rule added to
`CDerives` is picked up by rerunning it; `PDerives.ofC`'s cases are generated from the
constructors' explicit binders.

## Programs

`bc/` holds the acceptance programs of `docs/async-capabilities.md` §1 and the adversarial list
of §6.2, in provisional surface syntax. Each is marked pending (or `expect (designed)`) and ends
with today's `bcc check` message. `bc/lend-loop-term.bc` is the exception: it checks and runs
today (`i32[2113]`, `live 0`) and is what `LoopTerm.lean` reads.

| file | program |
|---|---|
| `bc/a1-scheduler.bc` … `bc/a6-cancel.bc` | A1–A6 |
| `bc/reject/n1-…` … `n9-…` | programs the design rejects |
| `bc/accept/m1-…` … `m3-…` | adversarial programs the design accepts, which must run cleanly |
