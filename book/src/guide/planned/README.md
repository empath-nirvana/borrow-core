# Planned features

The chapters in this section describe features that are designed or tracked but not yet
implemented. Nothing here is accepted by `bcc` today, and the syntax shown is not final. Each
chapter links the issue that tracks it; the chapter will be replaced by a guide chapter, with
runnable examples, when the feature lands.

A feature is done when it has a spec entry, core rules covered by the Fundamental Property and
adequacy, checker support, a lowering in the compiler, and a running corpus program (see
[Contributing](../../contributing.md)).
