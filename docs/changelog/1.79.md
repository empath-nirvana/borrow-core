- **1.79** (2026-11-10) — §73 (#981), §8: unsigned integers `U32` and `U64` as kernel widths.
  `Width` gains `u32` and `u64`, `IntLit` their literals; the grouped integer operations apply at
  them with the host's `…32`/`…64` functions on the same bits, the host gaining no field;
  `reinterpret_u`/`reinterpret_s` change the reading between same-size integers. No new `VTy` or
  `CTy` former, `CDerives` rule or relation clause.
